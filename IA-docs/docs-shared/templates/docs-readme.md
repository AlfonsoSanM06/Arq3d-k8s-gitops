# Documentación De <project-name>

Esta carpeta contiene conocimiento específico y verificable del proyecto.
Actualizarla en el mismo cambio que modifique arquitectura, infraestructura,
despliegue, recuperación o comportamiento operativo.

## Contenido

- `context.md`: componentes, entornos, dependencias y estado verificado.
- `architecture.md`: diseño, flujos, límites de confianza y recuperación.
- `deployment.md`: precondiciones, despliegue y validación.
- `decisions/`: decisiones de arquitectura (ADR).
- `diagrams/`: fuentes Mermaid y, cuando aporte valor, Excalidraw.
- `incidents/`: errores confirmados, causa raíz y prevención.
- `learning/`: explicaciones para comprender tecnologías y decisiones.
- `runbooks/`: procedimientos repetibles y seguros.

No registrar secretos, datos personales, logs completos ni hipótesis como si
fueran hechos. Cada documento operativo debe indicar la fecha de verificación
cuando describa estado real.
